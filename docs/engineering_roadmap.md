# 虚假信息检测系统工程化规划

## 当前架构

系统当前只保留两条检测路径：

- 多模态虚假信息检测：`MMD_Agent` 接收文本和图片，以一次视觉模型调用完成原子点解析、八维核查、五分类和解释。
- 深度伪造检测：`IFD_Agent` 通过视觉模型调度本地轻量化图像取证工具，输出图像三分类、可疑区域和解释。

网页输入负责抽取正文和代表图片，再进入 MMD 路径。AIGC 专项检测暂不实现。

## 近期重点

1. 在固定 MMD 验证集上持续校准五分类准确率，重点降低 `False` 过预测和图文 `Inconsistent` 误判。
2. 将单样本平均耗时稳定在约 20 秒，并记录模型调用和图像预处理耗时。
3. 建立深度伪造真实评测集，分别评估真实图、局部篡改图和合成图。
4. 校准视觉工具的适用条件、阈值和证据强度，避免将启发式分数视为真实概率。
5. 改善失败状态、证据不足和局限性的前端表达。

## 中期建设

- 支持网页多图和图注对应关系，而不是只检测代表图片。
- 为模型提示词、输出协议和工具策略增加版本化回归评测。
- 增加结构化日志、请求 ID、模型/工具耗时和错误分类。
- 为网页抓取增加 SSRF 防护、响应大小限制、MIME 校验和重定向审计。
- 增加会话及图像产物的生命周期和清理策略。

## 评测门禁

每次模型、提示词或工具策略变更至少记录：

- MMD Accuracy、Macro-F1、混淆矩阵和各标签召回率。
- 深度伪造三分类准确率、误报率、漏报率；有区域标注时增加 IoU。
- 技术成功率、平均/中位/P95 时延和失败原因分布。
- 典型错误样例及修改前后对比。

检测结果用于研究和演示，不替代人工核查。
