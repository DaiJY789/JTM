# 惊堂木 2.0 演示视频脚本

成片约 **2 分 45 秒**，中文旁白配桌面录屏。先演示如何核查一条图文消息，再演示如何检查一张图片的可疑区域。

## 分镜与口播

| 时间 | 屏幕操作 | 口播词 |
| --- | --- | --- |
| 0:00–0:18 | 开场先并排给出正文里的 `2.12%` 和配图里的 `0.28%`。小字标注「测试样本」，随后切回工作台。 | 同一条新闻里，正文写的住房通胀是百分之二点一二，配图却写着百分之零点二八。哪一处需要再核实？我们用惊堂木，把这组图文一起查一遍。 |
| 0:18–0:43 | 选择「多模态事实核查」→「新对话」。粘贴样例 A 正文，依次上传四张图片，点击「开始检测」。 | 我先把新闻正文贴进来，再加上它原来的四张配图。系统会提取正文里的关键说法，再把它们和配图逐一对照。 |
| 0:43–1:15 | 等待过程剪短。展开「核查结论与依据」，给「真伪混合」和主要理由留两秒。点开第 2 张图，停在住房和食品两行。 | 这次结果是真伪混合。食品数据在正文和图里都写着百分之三点四七，住房这一项却对不上。现在能确认的是，正文和配图给出了不同的数字。要判断哪个数字适用，还需要看原始统计发布和计算口径。 |
| 1:15–1:41 | 关闭大图，在对话框粘贴样例 A 的追问，点击「发送」。停留在实际回答中讨论证据局限的位置。 | 我再追问一句：这两个数字为什么值得复核？我们还缺什么证据？这样就可以顺着刚才的结果，继续查最有疑问的那一项。 |
| 1:41–2:03 | 选择「深度伪造检测」→「新对话」，上传样例 B。先给宝石蛇原图一个近景，再点击「开始检测」。 | 接下来只看一张图片。这条蛇的鳞片和宝石细节很逼真。我把它放进深度伪造检测，让系统结合画面细节和图像取证工具做判断。 |
| 2:03–2:32 | 等待过程剪短。展示「合成图像」标签和蛇头附近的标记，展开「核查结论与依据」。若实时结果没有标记，可切到已标明「历史检测结果」的回放。 | 在这次结果里，图片被判为合成图像。系统把蛇头附近标成可疑区域，方便我们回看鳞片的排列和宝石与表面的接合处。框的位置是模型估计的，可以用来定位复核重点。 |
| 2:32–2:45 | 回到结果页定格，画面保留「惊堂木 2.0」和两个任务入口。 | 遇到可疑消息，可以先对照正文和配图，再按需检查图片本身。把具体疑点找出来，就知道下一步该核实什么。 |

## 样例 A · 正文与配图数字不一致

**模式**　多模态事实核查  
**正文**　[复制 MMD 010 样例正文](sample/MMD-010/MMD-010.txt)。直接使用原文，录屏时只放大提到住房数据的段落。  
**配图**　按以下顺序上传，开场和讲解重点放在第 2 张。

1. [第 1 张 · 建筑外景](sample/MMD-010/010_01_img_1.jpg)
2. [第 2 张 · CPI 分类图卡](sample/MMD-010/010_02_img_2.jpg)
3. [第 3 张 · PCE 日历图卡](sample/MMD-010/010_03_img_3.jpg)
4. [第 4 张 · 建筑外景](sample/MMD-010/010_04_img_4.jpg)

**追问**　复制到检测完成后的对话框。

```text
正文里的住房通胀是 2.12%，第 2 张配图写的是 0.28%。请说明目前能确认什么，以及还需要哪些原始来源和统计口径才能判断哪个数字适用。
```

**已有结果**　左侧历史记录里选「华盛顿——美国 2 月份消费者通胀年…」。历史标签为「真伪混合」，界面置信度约 64%，运行时间约 20 秒。配图中的住房指标带有 `MoM`，正文没有交代该数值的统计口径。历史说明也注明，判断主要依据图文内部比对，官方原始数据有待核验。

## 样例 B · 检查一张宝石蛇图片

**模式**　深度伪造检测  
**图片**　[上传 OpenFake 54 原图](sample/OpenFake-54/0054.jpg)  
**已有结果**　左侧历史记录里选「OpenFake 数据集样本 54…」。历史标签为「合成图像」，置信度 95%，运行时间约 32 秒。OpenFake 对这张图的原始标注为 `fake`，「合成图像」是惊堂木给出的细分判断。

## 录制准备

- 用本地图片上传录制。先分别录下「提交」「结果」「追问」三个镜头，剪辑时保留从提交到结果的短转场。若插入旧结果，在画面上标「历史检测结果」。
- 两条历史都已在当前工作台的历史目录中。实时重跑的结论或框选区域可能不同，剪辑时以对应画面为准。追问建议先录到实际回复，备用剪法是省略追问镜头，直接切换到单图检测。
- 纯文本连通性备选可输入「月球是地球的天然卫星。」并点击「开始检测」。这是此前实测可运行的样例，适合录制前检查模型服务。
- 片尾素材字幕可写「图文样本 MMD 010 · 图片样本 OpenFake 54 · 检测结果用于辅助判断」。
